# 🚀 Smart Placement System

A modern web-based placement preparation tracker built with **Python, Flask, HTML, CSS, and SQLite**.

Smart Placement System helps students organize their placement preparation in one place — from DSA progress and technical subjects to projects and daily tasks.

---

## ✨ Features

### 🧠 DSA Tracker
- Track completed DSA lectures
- Track problems solved
- Monitor overall DSA progress
- Update progress anytime

### 📚 Subjects Tracker
- Track core technical subjects
- Update preparation percentage
- Monitor subject-wise progress
- Maintain consistent preparation

### 💻 Project Manager
- Add technical projects
- Store project descriptions
- Track project status
- Record technologies used
- Delete projects when needed

### 🎯 Daily Task Manager
- Create daily preparation tasks
- Track pending and completed tasks
- Mark tasks as completed
- Delete individual tasks
- Clear completed tasks
- View task statistics

### 🎨 Modern User Interface
- Dark professional design
- Responsive layout
- Glassmorphism-inspired cards
- Progress indicators
- Clean navigation
- Mobile-friendly interface
